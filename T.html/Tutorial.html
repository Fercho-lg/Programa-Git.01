Fundamentos Frontend

Tutorial práctico para principiantes absolutos sobre HTML5, CSS3 y JavaScript utilizando Visual Studio Code.

Introducción HTML Imágenes CSS JavaScript Proyecto

1. Introducción al desarrollo Frontend

El desarrollo Frontend corresponde a la parte de una página o aplicación web que el usuario puede visualizar y utilizar directamente.

Por ejemplo, cuando visitamos una tienda virtual podemos observar imágenes, botones, menús, productos, formularios y textos. Todos estos elementos forman parte de la interfaz que desarrolla el Frontend.

HTML

HTML se encarga de construir la estructura de la página.

CSS

CSS se encarga de controlar la apariencia visual de la página.

JavaScript

JavaScript permite agregar comportamiento e interacción.

Concepto fundamental: HTML construye la estructura, CSS define la apariencia y JavaScript agrega comportamiento.

2. Preparación del entorno de trabajo

Para desarrollar nuestro proyecto utilizaremos Visual Studio Code como editor de código.

Crear el proyecto

Primero debemos crear una carpeta en nuestro computador. Podemos llamarla: 

mi-primer-proyecto

Después abrimos esta carpeta desde Visual Studio Code.

Estructura recomendada 

mi-primer-proyecto/

│

├── index.html

│

├── css/

│   └── style.css

│

├── js/

│   └── script.js

│

└── img/

    └── imagen.jpg

Esta estructura permite mantener separados los diferentes componentes del proyecto.

  • index.html: estructura.
  • style.css: estilos.
  • script.js: JavaScript.
  • img: imágenes.

3. Fundamentos de HTML5

HTML significa HyperText Markup Language . Se utiliza para organizar el contenido de una página web.

Estructura básica 

<!DOCTYPE html>

<html lang="es">

<head>

    <meta charset="UTF-8">

    <title>
        Mi primera página
    </title>

</head>


<body>

    <h1>
        Hola mundo
    </h1>

    <p>
        Esta es mi primera página.
    </p>

</body>

</html>

¿Qué significa cada parte?

<!DOCTYPE html> indica que estamos utilizando HTML5.

<html> representa el elemento principal del documento.

<head> contiene información de configuración del documento.

<body> contiene todo aquello que será visible para el usuario.

<h1> representa un título principal.

<p> representa un párrafo.

Otras etiquetas importantes 

<h1>Título principal</h1>

<h2>Subtítulo</h2>

<p>Párrafo</p>

<a href="pagina.html">
    Enlace
</a>

<button>
    Botón
</button>

<ul>

    <li>
        Elemento
    </li>

</ul>

4. Cómo añadir imágenes en HTML

Para utilizar imágenes en nuestro proyecto debemos primero almacenarlas dentro de una carpeta.

Por ejemplo: 

mi-primer-proyecto/

├── index.html

└── img/

    └── paisaje.jpg

Desde nuestro archivo HTML podemos insertar la imagen utilizando: 

<img
    src="img/paisaje.jpg"
    alt="Paisaje natural"
>

¿Qué significa este código?

<img> indica que queremos insertar una imagen.

src significa "source" o fuente. Indica dónde está ubicada la imagen.

alt contiene una descripción alternativa de la imagen.

Importante: Si la imagen no aparece, debemos revisar principalmente el nombre del archivo, su extensión y la ruta escrita en src.

Cambiar el tamaño mediante CSS 

.imagen {

    width: 300px;

    height: auto;

}

Y posteriormente: 

<img
    class="imagen"
    src="img/paisaje.jpg"
    alt="Paisaje natural"
>

Imagen mediante una dirección de Internet 

<img
    src="https://ejemplo.com/imagen.jpg"
    alt="Descripción de la imagen"
>

Para comenzar, se recomienda trabajar con imágenes almacenadas dentro del propio proyecto porque permite comprender mejor el funcionamiento de las rutas.

5. Fundamentos de CSS3

CSS significa Cascading Style Sheets . Su función es modificar la apariencia de los elementos HTML.

Ejemplo básico 

p {

    color: black;

    font-size: 18px;

}

En este ejemplo:

  • p es el selector.
  • color modifica el color.
  • font-size modifica el tamaño.

Clases CSS 

.titulo {

    color: black;

    font-size: 32px;

    text-align: center;

}

La clase puede utilizarse desde HTML: 

<h1 class="titulo">

    Mi página web

</h1>

Propiedades fundamentales

  • color — color del texto.
  • background — fondo.
  • font-size — tamaño de letra.
  • margin — espacio exterior.
  • padding — espacio interior.
  • border — borde.
  • width — ancho.
  • height — altura.

Modelo de caja 

.tarjeta {

    width: 300px;

    padding: 20px;

    border: 1px solid black;

    margin: 20px;

}

Todos los elementos HTML pueden entenderse como cajas que poseen contenido, espacio interno, borde y espacio externo.

6. Fundamentos de JavaScript

JavaScript permite agregar interacción y comportamiento a una página web.

Variables 

let nombre = "Usuario";

let edad = 25;

Las variables permiten almacenar información que posteriormente podemos utilizar.

Funciones 

function saludar() {

    alert("Hola mundo");

}

Una función agrupa instrucciones que pueden ejecutarse cuando sea necesario.

Eventos 

<button onclick="saludar()">

    Saludar

</button>

onclick indica que la función debe ejecutarse cuando el usuario haga clic.

Modificar contenido HTML 

<p id="mensaje">

    Texto original

</p>


<button onclick="cambiarTexto()">

    Cambiar texto

</button>


<script>

function cambiarTexto() {

    document
        .getElementById("mensaje")
        .textContent =
        "Texto actualizado";

}

</script>

getElementById() permite encontrar un elemento HTML mediante su identificador.

textContent permite modificar el texto de ese elemento.

Ejemplo interactivo

Presiona el botón.

7. Integración de HTML + CSS + JavaScript

En un proyecto real las tres tecnologías trabajan juntas.

HTML define qué elementos existen.

CSS define cómo se ven.

JavaScript define qué sucede cuando el usuario interactúa. 

HTML
 ↓
Estructura

CSS
 ↓
Diseño

JavaScript
 ↓
Interacción
Regla práctica: Antes de escribir código pregúntate:

¿Qué necesito mostrar? → HTML
¿Cómo quiero que se vea? → CSS
¿Qué debe ocurrir cuando el usuario interactúe? → JavaScript

8. Proyecto práctico final

Ahora construiremos una pequeña tarjeta de producto aplicando los conocimientos aprendidos.

HTML 

<div class="producto">

    <img
        src="img/producto.jpg"
        alt="Producto">

    <h2>
        Producto de ejemplo
    </h2>

    <p>
        Descripción del producto.
    </p>

    <strong>
        $99.999
    </strong>

    <button onclick="comprar()">

        Comprar

    </button>

    <p id="resultado"></p>

</div>

CSS 

.producto {

    width: 300px;

    padding: 20px;

    border: 1px solid #000;

    text-align: center;

}


.producto img {

    width: 100%;

    height: auto;

}


.producto button {

    background: #000;

    color: #fff;

    border: none;

    padding: 10px 20px;

    cursor: pointer;

}

JavaScript 

function comprar() {

    document
        .getElementById("resultado")
        .textContent =
        "Producto agregado correctamente.";

}

¿Qué ocurre en este ejemplo?

  1. HTML crea la tarjeta.
  2. HTML carga la imagen.
  3. CSS define la apariencia.
  4. El usuario presiona el botón.
  5. JavaScript ejecuta la función.
  6. El mensaje cambia en pantalla.

9. Errores frecuentes

La imagen no aparece

Revisar:

  • Nombre del archivo.
  • Extensión.
  • Carpeta.
  • Ruta escrita en src.

El CSS no funciona

Revisar que el archivo esté correctamente conectado: 

<link
    rel="stylesheet"
    href="css/style.css"
>

JavaScript no funciona

Revisar la consola del navegador y comprobar que los nombres de las funciones y elementos coincidan exactamente.

La página se ve desorganizada

Revisar principalmente: margin, padding, width, height y display.

10. Ejercicio final

Para comprobar los conocimientos adquiridos, se propone crear una página web sencilla desde cero.

Requisitos

  • Crear un archivo HTML.
  • Crear un archivo CSS.
  • Crear un archivo JavaScript.
  • Crear una carpeta para imágenes.
  • Añadir al menos una imagen.
  • Crear un título.
  • Crear varios párrafos.
  • Crear una tarjeta.
  • Crear un botón.
  • Hacer que el botón ejecute JavaScript.
  • Mostrar un mensaje al usuario.
Objetivo: El estudiante debe demostrar que comprende la relación entre HTML, CSS y JavaScript, y que puede incorporar correctamente imágenes dentro de un proyecto frontend.

Conclusión

HTML, CSS y JavaScript constituyen una base fundamental para comenzar a desarrollar interfaces web.

HTML permite construir la estructura, CSS permite diseñar la interfaz y JavaScript permite agregar interacción.

El aprendizaje debe realizarse principalmente mediante la práctica. No es necesario memorizar todo el código desde el principio.

Lo más importante es comprender qué función cumple cada elemento y aprender a buscar, probar y corregir errores.
